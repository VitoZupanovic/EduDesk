# Course files

Files in this folder are served by the Vite frontend from the site root.

Examples:

- `frontend/public/files/course1/lecture1.pdf` is available as `/files/course1/lecture1.pdf`
- `frontend/public/files/course1/lecture2.pdf` is available as `/files/course1/lecture2.pdf`
- `frontend/public/files/course2/intro.pdf` is available as `/files/course2/intro.pdf`
- `frontend/public/files/course2/exercises.pdf` is available as `/files/course2/exercises.pdf`
- `frontend/public/files/course3/robotics_basics.pdf` is available as `/files/course3/robotics_basics.pdf`
- `frontend/public/files/course3/lab_guide.pdf` is available as `/files/course3/lab_guide.pdf`
- `frontend/public/files/course4/DemoLecture1.pdf` is available as `/files/course4/DemoLecture1.pdf`

Use these public paths as the `File link` value in the app.
